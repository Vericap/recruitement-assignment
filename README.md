## Assignment: Project Questionnaire API

### Objective:

The objective of this project is to build a simple React-based user dashboard. The dashboard should display user information, allow updates, and display data from an API. Focus on clean and responsive design, data handling, and component-based architecture.

## Requirements:

### Functionalities:
1. **Dashboard Layout:** Create a simple dashboard layout with:
   - A navigation bar.
   - A sidebar for navigation options (e.g., `Profile`, `Settings`).
   - A main content area to display user data.
2. **Profile Section:**
   - Display user information (e.g., `name`, `email`, `etc`).
   - Provide a form to update the user’s name and email. Use state management to handle form inputs and updates.
3. **Fetch and Display Data:**
   - Fetch user data from a public API (e.g., `https://jsonplaceholder.typicode.com/users`) and display it in a table.
   - Include search functionality to filter through the user list.
4. **Responsive Design:**
   - Ensure the dashboard is fully responsive for different screen sizes, including desktop and mobile views.

### Design Considerations:
1. Use **HTML** for creating the basic structure of components.
2. Use **CSS** or **SCSS** for styling the components and making the dashboard responsive.
3. Use **JavaScript** for logic and handling events.
4. Use **ReactJS** to create functional components and manage state.

### Bonus Points:
1. Use **React** Hooks like useState and useEffect for managing component state and lifecycle.
2. Implement **React Router** for navigating between different sections of the dashboard.
3. Use **Axios** or the Fetch API for making API requests.

### Data Handling:
1. Display a loading indicator while fetching data.
2. Handle errors gracefully and display appropriate error messages when API requests fail.

### Deliverables:

1. Source code for the React application.
2. A brief explanation of the design choices made (e.g., component structure, CSS techniques).
3. `README` file with setup and testing instructions, explaining how to run the project locally.
4. At last, submit your public repository with us.

### Testing Instructions:

1. Test the responsiveness of the dashboard by resizing the browser window or using developer tools.
2. Verify that the search functionality filters the user data correctly.
3. Test form validation for updating the user’s name and email.
4. Ensure proper error messages are displayed when API requests fail.
