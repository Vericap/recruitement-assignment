## Assignment: ToDo App Review

### Objective:
Evaluate your ability to write test cases, perform testing, and report bugs. You’ll work with a simple web app to assess its functionality.

## Requirements:
---

### Write Test Cases:
1. Write 5 test cases for the following:
   - Adding a new task.
   - Marking a task as completed.
   - Editing a task.
   - Deleting a task.
   - Filtering tasks (All, Active, Completed).

2. Include: **Test ID**, **Scenario**, **Steps**, **Expected Result**, **Actual Result**, **Status** (Pass/Fail).


### Report Bugs:
1. Identify 2 potential bugs in the app.
2. For each bug, include: Description, Steps to Reproduce, Expected Result, Actual Result, Severity.

### Application To Review
[Please refer this sample ToDo app](https://todomvc.com/examples/react/dist/)

### Deliverables:

1. Submit a PDF with your test cases and bug reports.
2. Share the repository link with us.
